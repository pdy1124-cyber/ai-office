# Park Lab AI Office

브로·인스팅트·뮤즈 3인이 **실사 오피스**에서 움직이며 **Google Drive 결재라인**(오더 → 제작 → 검토 → 보고 → 수정 → 최종 승인 → 업로드)을 도는 정적 대시보드 (v3.0).

- 라이브: https://pdy1124-cyber.github.io/ai-office/
- 정적 페이지: `index.html` + `assets/*.webp` (외부 라이브러리·CDN·폰트 0개, 오프라인에서도 동작)
- GitHub Pages — `main` 브랜치 `/ (root)` 에서 그대로 서빙 (빌드 없음, Actions minutes 미사용)

## 결재라인 흐름 (`SEQ`)

1. **브로** 오더 하달 — 3인 회의실 브리핑. 오더 카드는 `muse_staging/`
2. **뮤즈** 제작 — 영상·목소리. 완성본 `muse_staging/`
3. **뮤즈 → 인스팅트** 보고, 1차 검토 (팩트·수치·로고) — `작업요약_인수인계/`
4. **인스팅트 → 브로** 보고
5. **수정 루프** — 브로 수정 지시 → 뮤즈 v2 → 인스팅트 재검토 → 브로 재보고
6. **브로 → 박시영 (최종 승인자)** 상신, 최종 승인 — `작업요약_인수인계/`
7. **인스팅트** 업로드 — `auto_upload_queue/` → 게시

> 화면의 흐름은 표준 경로를 보여주는 **시연**입니다. 실제 오더·승인 기록은 Drive 폴더에 남고, 발행은 승인 이후에만 진행됩니다.

## 좌표·데이터 수정

CSS 좌표는 모두 장면 대비 %입니다.

- `SPOT` — `broDesk` `instinctDesk` `museDesk` `ceoSpot` `meet` (바닥 기준점, 카드는 그 위에 섬)
- `MEET_OFFSET` — 회의실에서 3인이 겹치지 않게 하는 오프셋
- `ZONES` — 존 마커 `x` `y` 좌표·말풍선 문구
- `SEQ` — 결재 단계(`tl` 타임라인 인덱스, `dur` ms, `moves` [누가, 어디로, 서류 여부], `st` 상태, `say` 대사, `hud` Drive 경로)
- `TLINE` — 결재라인 7단계 라벨·담당·Drive 경로
- `DATA` — 현황판 수치(실제 기록만)

## 반응형

- 1180px 이하: 패널 316px, 결재라인 4열, 팀 카드 2열
- 1020px 이하: 1열 스택, 결재라인 3열
- 760px 이하: 캐릭터 카드 44px, 말풍선 158px, 결재라인 2열
- 430px 이하: 카드 38px, 존 라벨 숨김, 결재라인 1열
- `prefers-reduced-motion`: 이동 전환·걷기 바운스·스탬프 전환을 끔(단계는 그대로 진행)

## 원칙

- 화면 수치는 워크스페이스 실제 기록(발행 결과·스케줄 메타)에서만 가져옵니다. 가짜 값 없음.
- 개인정보(연락처·주소·이메일·계좌·가족/여행 일정·주식)는 담지 않습니다. 이름·직함은 최종 승인자 표기(`박시영 (최종 승인자)`)만 사용합니다.
- 배경·멤버 아바타는 AI 생성 이미지이며 실제 인물이 아닙니다. 모든 이미지는 `assets/*.webp` 로컬 파일입니다.
