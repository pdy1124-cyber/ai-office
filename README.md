## 좌표·데이터 수정

CSS 좌표는 모두 장면 대비 %입니다.

- `SPOT` — `broDesk` `instinctDesk` `museDesk` `ceoSpot` `meet` (바닥 기준점, 카드는 그 위에 섬)
- `MEET_OFFSET` — 회의실에서 3인이 겹치지 않게 하는 오프셋
- `ZONES` — 존 마커 `x` `y` 좌표·말풍선 문구
- `PEOPLE` — 멤버·계정 상세(`name` `handle` `role` `rows` `links` `say`). 계정 타일은 `kind:"clone"` + `initials`
- `SEQ` — 결재 단계(`tl` 타임라인 인덱스, `dur` ms, `moves` [누가, 어디로, 서류 여부], `st` 상태, `say` 대사, `hud` Drive 경로)
- `TLINE` — 결재라인 7단계 라벨·담당·Drive 경로
- `DATA` — 현황판(`videos` `blogs` `schedules{hh,mm}` `system` `today`). 스케줄은 시각만 넣으면 다음 회차를 계산

## 반응형

- 1180px 이하: 패널 316px, 결재라인 4열, 팀 타일 3열
- 1020px 이하: 1열 스택, 결재라인 3열, 원칙·오늘처리 2열
- 760px 이하: 캐릭터 카드 44px, 말풍선 158px, 결재라인 2열, 팀 타일 2열

- `prefers-reduced-motion`: 이동 전환·걷기 바운스·스탬프 전환을 끔(단계는 그대로 진행)

- 화면 수치는 워크스페이스 실제 기록(발행 결과·스케줄 메타)에서만 가져옵니다. 가짜 값 없음 — 공개 전인 영상은 **ID 없이** 상태만 표시합니다.
- 개인정보(연락처·전화번호·주소·이메일·계좌·가족/여행 일정·주식)는 담지 않습니다. 표기하는 계정은 공개 활동 핸들(`@pdy1124` 등)뿐입니다.
