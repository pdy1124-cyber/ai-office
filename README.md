# Park Lab AI Office

브로·인스팅트와 5개 브랜드 워크스테이션이 일하는 **2.5D 아이소메트릭 오피스 + 모던 다크 대시보드** (v2.1 — 실제 캐릭터 아바타).

- 라이브: https://pdy1124-cyber.github.io/ai-office/
- 정적 페이지: `index.html` + `assets/*.webp` (외부 라이브러리·CDN·폰트 0개, 오프라인에서도 동작)
- GitHub Pages — `main` 브랜치 `/ (root)` 에서 그대로 서빙 (빌드 없음, Actions minutes 미사용)

## 구성

| 영역 | 내용 |
|---|---|
| 오피스 씬 | 따뜻한 간접조명과 통유리 야경의 2.5D 아이소메트릭 배경(`assets/office_bg.webp`, 1672×941) 위에 HTML/CSS 핀 오버레이. 브로(중앙 데스크)·인스팅트(서버랙)·골프랩·꿀팁랩·1분 용어사전·사운드랩·싸다싸 5개 워크스테이션 + 콘텐츠 기획·편집 회의실·라운지 존. 핀은 **원형 캐릭터 아바타(테두리 글로우)** + 부유 애니메이션 + 상태 점, 서버랙 LED 열은 26개 점멸. |
| 상호작용 | 핀·칩 클릭 → 옆 글래스 상세 패널(역할·상태·링크). 호버/선택 시 글래스 말풍선이 실제 작업 문구 표시, 미선택 시 5.6초 간격 자동 순환. 장면 위 마우스 이동에 따른 미세 시차(parallax). |
| 헤더 | 실시간 시계·요일, 데이터 스냅샷 시각, LIVE 표시 |
| 현황판 | 유튜브 4편(공개 영상 ID) · 블로그 81·82·83호 발행 상태 · 다음 스케줄 실시간 카운트다운 · 자동화 시스템 상태. **주식·투자 항목 없음.** |

## 반응형

- 1440px 이상: 씬 + 344px 상세 패널, 현황판 3열(유튜브·스케줄 2칸)
- 1020px 이하: 1열 스택, 현황판 2열 → 1열
- 480px 이하: 핀 축소(34px, 아바타 얼굴 유지)·이름 라벨 숨김·존 핀 숨김, 하단 칩(21px 아바타)으로 전체 선택

## 데이터 갱신

`index.html` 안의 `DATA`(현황판)와 `PEOPLE`/`PROPS`(캐릭터·존, 핀 좌표 `x`·`y` 는 배경 이미지 대비 %)를 고치면 화면 전체가 바뀝니다.

- `DATA.videos` — 채널·영상 ID·제목·길이·상태
- `DATA.blogs` — 호수·슬롯 시각·발행 상태·링크
- `DATA.schedules` — ISO 8601 시각(+09:00)과 라벨. 카운트다운/HUD가 자동 계산
- `DATA.system` — 자동화 상태 값

수정 후 `git push` 하면 GitHub Pages가 1분 안에 자동 반영합니다.

## 원칙

- 화면의 수치는 워크스페이스 실제 기록(발행 결과·스케줄 메타)에서만 가져옵니다. 가짜 값 없음.
- 개인정보(실명·연락처·주소·이메일·계좌·API 키·가족/여행 일정)는 담지 않습니다. 공개 브랜드·캐릭터명·공개 영상 ID·작업 상태만 표시합니다.
- 배경 일러스트와 캐릭터 아바타는 `images` 로 생성·가공한 로컬 이미지이며, 실제 인물은 골프랩 공식 모델 사진(브랜드 공개용) 외에 없습니다.
