# Park Lab AI Office

브로·인스팅트와 5개 브랜드 부스가 일하는 **픽셀 가상 사무실 + 실시간 현황판** (1차 프로토타입).

- 라이브: https://pdy1124-cyber.github.io/ai-office/
- 단일 파일 정적 페이지: `index.html` (외부 라이브러리·CDN·폰트 0개, 오프라인에서도 동작)
- GitHub Pages — `main` 브랜치 `/ (root)` 에서 그대로 서빙 (빌드 없음, Actions minutes 미사용)

## 구성

| 영역 | 내용 |
|---|---|
| 사무실 캔버스 | 384×216 픽셀 캔버스. 브로(파란 ㅂ 캐릭터)가 책상·화이트보드·회의 테이블·서버랙 사이를 걸어다니고, 인스팅트(보라/청록 AI)가 서버랙 앞에 떠 있음. 골프랩·꿀팁랩·1분 용어사전·사운드랩·싸다싸 5개 부스, 화이트보드(오늘 목표)·서버랙(GitHub Actions)·회의 테이블(콘텐츠 기획·편집) 소품. 벽시계는 실제 시각. |
| 상호작용 | 캐릭터·부스·소품 클릭 → 옆 상세 패널(역할·상태·링크). 말풍선은 실제 작업 문구가 번갈아 표시. 작은 화면에서는 칩 버튼으로 열람. |
| 현황판 | 유튜브 4편(공개 영상 ID) · 블로그 81·82·83호 발행 상태 · 다음 스케줄 실시간 카운트다운 · 자동화 시스템 상태 |

## 데이터 갱신

`index.html` 안의 `DATA` 객체(그리고 캐릭터별 문구는 `PEOPLE`)만 고치면 화면 전체가 바뀝니다.

- `DATA.videos` — 채널·영상 ID·제목·길이·상태
- `DATA.blogs` — 호수·슬롯 시각·발행 상태·링크
- `DATA.schedules` — ISO 8601 시각(+09:00)과 라벨. 카운트다운/HUD가 자동 계산
- `DATA.system` — 자동화 상태 값

수정 후 `git push` 하면 GitHub Pages가 1분 안에 자동 반영합니다.

## 원칙

- 화면의 수치는 워크스페이스 실제 기록(발행 결과·스케줄 메타)에서만 가져옵니다. 가짜 값 없음.
- 개인정보(실명·연락처·주소·이메일·계좌·API 키·가족/여행 일정)는 담지 않습니다. 공개 브랜드·캐릭터명·공개 영상 ID·작업 상태만 표시합니다.
