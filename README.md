## 좌표·데이터 수정

CSS 좌표는 모두 장면 대비 %입니다.

- `SPOT` — `museDesk` `seconDesk` `broDesk` `instinctDesk` `ceoSpot` `meet` (바닥 기준점, 카드는 그 위에 섬)
- `DESK_OF` — 캐릭터 → 책상 스팟 매핑 / `WALKER_IDS` — 장면에서 걷는 캐릭터 순서
- `MEET_OFFSET` — 회의실에서 4인이 겹치지 않게 하는 오프셋
- `ZONES` — 존 마커 `x` `y` 좌표·말풍선 문구
- `PEOPLE` — 멤버·계정 상세(`name` `handle` `role` `badge` `img` `rows` `links` `say`)
- `SEQ` — 결재 단계(`tl` 타임라인 인덱스, `dur` ms, `moves` [누가, 어디로, 서류 여부], `st` 상태, `say` 대사, `hud` Drive 경로)
- `TLINE` — 결재라인 7단계 라벨·담당·Drive 경로
- `DATA` — 현황판(`kpi` `videos` `blogs` `schedules{hh,mm,off}` `system` `today` `guides` `stack` `pipe`). 스케줄은 시각만 넣으면 다음 회차를 계산
